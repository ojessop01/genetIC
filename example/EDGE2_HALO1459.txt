# 
# If alpha_k_limits_from_boxsize is enabled:
#   - k_min is set to 2*pi/boxsize (the fundamental mode of the simulation box)
#   - k_max is determined by one of two methods (see below)
# This restricts the alpha integral to modes actually present in your simulation.
# NOTE: base_grid (and zoom_grid if using alpha_k_max_from_grid) must be defined BEFORE camb.
#

# k_max can be set in two ways:
#   1. Hardcoded value (default): use alpha_k_max to specify a fixed value in h/Mpc

#
#   2. Grid-derived Nyquist frequency: use alpha_k_max_from_grid to calculate k_max

#alpha_k_max_from_grid false
